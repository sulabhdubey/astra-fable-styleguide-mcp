# v0.8.0 release notes

v0.8.0 adds guided local setup and clearer verification evidence. Use the installer,
CLI archive and checksums from the same release. Attached release evidence identifies
the exact tested source. These additions are absent from the v0.7.0 archive.

## Changes

- Guide React/Vite configuration in Local Studio: review resolved canonical tokens,
  source/build identity and the exact configuration before saving. Existing files
  are never overwritten; changed inputs require another review.
- Report evaluated and incomplete checks, actual selectors, and separate journey
  and measurement viewport sizes in Studio, text and HTML reports.
- Clear stale results and repair authorization when rechecking, including after a
  failed check. Lock workspace controls during operations and restore keyboard focus.
  Valid undo receipts remain subject to source verification.
- Reject duplicate journey IDs, duplicate measurement labels/selectors and empty
  rule groups. Missing viewport evidence stays `not_checked`.
- Verify the guided flow in source and installed-archive browser tests, CI and the
  release gate. Clarify developer pilot setup and evidence permissions.

## Compatibility and limits

Existing valid configurations remain supported. Ambiguous duplicate configurations
and empty measurements now fail validation; combine rules for one element into one
measurement and use distinct journey IDs. Canonical design token values are unchanged.

The wizard configures one dialog journey and one initially visible measurement target,
using bundled font-size/top-padding rules. It does not start project scripts, contact
the preview during setup, or grant repair authorization. Users must start a trusted
production preview and run browser checks. Richer configurations, pinned constitutions
and supported literal CSS repairs use explicit reviewed mappings.

Counts describe recorded checks, not whole-application coverage. Screen-reader behavior,
unsupported focus surfaces and unexercised states remain outside verified scope. This
release does not establish external adoption or an advantage from agent collaboration.
