# v0.10.1 release notes

v0.10.1 is a security and verification update. Existing design rules and supported
CLI workflows remain unchanged; this release does not include the separate
Storybook integration under review.

## Dependency fixes

- MCP Node 2.1.2, Server 2.4.0 and Client 2.3.0.
- Vite 8.3.3 and Zod 4.6.6.
- A narrow Undici override raises affected 8.x installations to 8.12.2.

No new advisory suppression is introduced. The existing pinned
http-cache-semantics repair and its named audit exception remain documented in
[SECURITY.md](../SECURITY.md) and exercised against the installed dependency.

## Continuous verification

PR and release gates check dependency advisories and fetched Git history using
checksum-verified Gitleaks 8.30.1. A daily workflow refreshes security checks.
Tracked private environment files and local state are blocked separately.
Synthetic controls verify that inline allow comments and the filename of an old
checksum false positive cannot hide a new secret. Historical exclusions identify
only six independently verified checksum occurrences in immutable commits.

## Compatibility and limits

The MCP endpoint remains read-only by default. Its protocol revision, eight
public tools and provider-independent Astra/Fable roles are unchanged. Canonical
manifest and CLI versions advance together to 0.10.1; design token values do not
change. Existing pinned constitutions keep their prior versions until explicitly
reviewed and adopted.

The release gate verifies the installer/archive in a clean consumer, browser
workflows and both Docker targets. See attached release evidence for the exact
commit and completed checks. Secret scans cover fetched refs, not every cached
copy, external fork or deployment artifact. Passing checks do not establish
formal security or compliance certification.
