# v0.5.1 release notes

## Dialog verification boundaries

- Detected embedded content, open shadow roots, implicit details summaries, focus-trap exceptions and visible semantic overlays now produce unsupported results for affected dialog checks.
- Scope risks are retained in the report. Nested-overlay Escape handling is not presented as a supported outer-dialog dismissal verdict.
- Explicit summary elements are included in traversal bounds.
- Eleven Chromium fixtures cover these boundaries plus autofocus, container focus and restoration. Both CI and the Release Gate run this regression.

## Compatibility and limits

Canonical design rules are unchanged. Reports include additive scope-risk metadata; affected checks may now be unsupported instead of passing or failing. Unsupported results indicate incomplete coverage and require a dedicated journey or manual review.

Closed shadow roots, unmarked custom overlays and arbitrary nested interaction paths remain outside reliable detection. Browser role/name and keyboard checks do not establish screen-reader behavior or complete accessibility. Native dialog containment preserves observed results rather than assuming compliance.

The CLI remains available by building and packing the source; it is not published to npm.
