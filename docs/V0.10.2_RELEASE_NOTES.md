# v0.10.2 release notes

The public MCP service now uses `@hono/node-server` 2.1.3 through its existing MCP Node adapter. This addresses [GHSA-rmxm-3fg6-px4f](https://github.com/advisories/GHSA-rmxm-3fg6-px4f), a double-decoding issue in the adapter's static file middleware. The fix uses an upstream version supported by the MCP dependency. The existing dependency audit policy still applies.

The [getting-started guide](START_HERE.md) now distinguishes three ways to use the project. Use the hosted MCP to retrieve design rules, the local checker to measure a configured interface, or the optional Astra/Fable workflow to compare proposals. The guide includes a deliberate 24px button failure that you can reproduce locally.

The constitution and CLI advance to 0.10.2. Token values, supported UI checks and the public MCP tool set are unchanged. The [installation guide](INSTALLATION.md) explains how to verify the release archive and installer before use.
