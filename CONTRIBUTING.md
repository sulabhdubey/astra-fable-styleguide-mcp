# Contributing

1. Open an issue or proposal describing the problem and trade-offs.
2. Do not edit `/generated` by hand.
3. Changes to `/spec` should be represented as explicit proposals/decisions.
4. Add regression tests for behavioral changes.
5. Run `pnpm verify` before requesting review in a connected environment.

PRs should state: Problem, Approach, Files changed, Tests executed, Risks, Follow-up work.
